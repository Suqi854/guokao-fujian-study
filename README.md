# 知序 · 国考与福建省考学习工作台

独立静态网站，面向手机，也适配平板和桌面。无需 ChatGPT、登录服务或 API 密钥；部署后运行不依赖 GPT 订阅。当前源码为**知识基础版 v0.30 候选**；手机尺寸与触屏实测待补，不是完整考试教材或真题库。

访问：[GitHub Pages 网站](https://suqi854.github.io/guokao-fujian-study/)；查看站内“资料来源与覆盖”了解依据、年份及尚待补充的范围。

## 本版内容和功能

- 88 篇讲义：资料分析11、判断推理13、言语理解12、数量关系16、政治理论10、常识判断9、福建专题1、申论方法16。
- 519 道原创选择题：资料分析91、判断推理105、言语理解88、数量关系125、政治理论58、常识判断44、福建专题8。均非历年真题。
- 62 个原创虚构材料写作练习（30份不同材料）：概括、对策、应用文、文章、综合分析，含一组地方情境训练，包括材料拆解、答案修改、对策落实、应用文对象、论证段、句意解释及同材料不同任务训练。早期文章任务提供提纲，w19和w47提供完整文章训练，w47为600—900字任务、793字符参考表达；均非官方评分，无自动打分。
- 5 个原创交互图形演示：同步旋转、并集/交集/异或、正方体相对面、柱高投影与整体旋转、方格数量与属性；图形题使用原创示意图。
- 35 项公开事实与范围参考资料：来源、年代与核验范围集中在资料说明中，知识页不逐点展示；解题方法、数学例子与练习独立编写。大纲只用于核对2026年度题型范围，不据此保证新年度覆盖。
- 题库检索：关键词、模块、题型、知识点、学习方向、真题来源、年份、难度标定、本机作答状态。可练筛选结果；目前真题来源为空、原创题无考试年份、难度未标定。
- 7个同知识点方法对照，每个有2份出处；共17份方法资料，区分8份历史教学资料、4份署名文章和5份机构资料。定义判断、估算与细节判断已有两份具名教学资料，其他专题仍有缺口，不转载商业题、模板或全文。
- 435道选择题按识别概念、迁移运用、检查边界各145题编排；可按训练层次筛选。层次是编写目标，不是经样本标定的难度；此前84题保持未分层。
- 福建2026考情快照：官方公告、分类合格线与核验缺口；没有把旧年度规则当2027安排。
- 针对性练习：先按模块与训练目标筛选，本机最近答错优先、未练题补足，跨知识点轮流取题，最多12题；显示规则和原因，不推断能力或遗忘周期。
- [覆盖矩阵](COVERAGE.md)：按模块和建设状态检索88个已有专题及24处明确缺口，显示实际讲义、题目和写作任务数量；不宣称官方完整范围或完成率。
- 分层学习：知识地图提供小白入门、基础巩固、高手提升入口。当前70课已逐层编写，其他18课仍可读完整讲义；本轮并行增加行测4课、政治4课、申论1课，不把新增课误记为原18课已完成。每层有对应讲解与原创训练，不冒称已有全站分层或能力诊断。来源说明集中留档，知识页保留更新日期与必要版本。
- 新行测4课配36题，新政治4课配24题，均给出四选项说明；政治使用指定年份的经核文本，区分原作、事件、网页与实施状态，不冒充完整现行政策。既有CPI及法律边界保留，累计2组表格材料，9道新阅读题将各自3段材料完整内嵌题干。申论62任务、30材料及五类三层路径，各任务草稿和自查独立保存。路径是学习目标，不是经样本标定的难度。
- 两条学习线：首页与知识地图保留分类错题和申论入口，并新增`#theory`政治理论路线，八主题依次进入三层讲义与原创题。已读进度沿用原记录，不自动判掌握、不设假定备考时长，不预测分数；历史理论不替代近年政策核验。
- 多表共用材料与逐项解析：v0.8起及此后新增的390题给出每个选项的判断理由，选择题提交后展开；旧题尚未全部补齐逐项说明。
- 本轮申论新增农业、工艺、海岸3组24段虚构材料，每组五类任务；参考折叠区可看材料段号依据、弱表达诊断与改写、二稿步骤。新增完整长文参考为779及992字符，非官方答案。
- 搜索、分类、收藏、已读标记、个人笔记、配套练习、综合练习、逐题解析、错题重练、学习统计。
- 申论按五类任务、关键词与本机草稿状态交集筛选，明确命中数量；同材料的不同设问互相链接，答案分别保存。
- 申论草稿即时保存、字数自查、参考要点、自查勾选、草稿 TXT 导出。
- 训练记录与复盘：自选1至20道固定原创题，填写1至240分钟预算；按模块保存正确、错误、未提交及运行用时。计时含阅读和解析停留，后台及未暂停关闭页面计入，站内离开会暂停；到时结束，未提交不计错误。结束确认弹窗的停留也计入运行时间（已暂停则不计），以确认完成时结算。没有官方分值或总分预测。
- 申论计时与手动完成：一次只运行一个计时任务，暂停与结束分开；草稿、勾选、用时和手动完成各自记录。计时不是纯写字时间，也不是自动阅卷。最多保留500组历史，不自动删除旧记录。
- 八个政治理论主题提供学习重点、易混对照、白话例子、理解线索和先答后核对的回忆问题。重点按理解顺序提炼，不宣称官方考频或已掌握；保留经典年代与政策另核边界。
- 完整 v2 JSON 备份和恢复，也支持导入旧 v1 备份；导入先校验，再确认替换。备份中的活动计时暂停，当前页面的运行状态不因导出而改变；恢复后不会猜算跨设备空档。损坏数据不会被静默覆盖。读取权限后来受限时，原文导出可回退最近缓存，并用文件名和提示注明不保证最新；无缓存时不生成假空文件。

数量不代表学精：其余18课未分层，练习变式和真实跨材料训练仍不足。新行测每层3题，政治每层2题，申论每层5任务；这些是教学组织，不是实测难度或官方完整覆盖。

已扩为政治理论八主题入门路线；仍未覆盖完整政治理论和年度时政、断代史与文学全体系、复杂空间重构、全部言语数量题型、福建文化与政策专题。既有知识手册及原型未成功下载，未并入本版。备考方向仅记录目标，本版不是两套独立题库。所有旧版记录ID保持不变，旧笔记、草稿、自查和作答可以继续使用并恢复v1备份；不能从旧逐题记录补造历史批次。

## 本地预览

需要 Python 3：

```sh
python3 -m http.server 4173 --directory docs
```

打开 `http://localhost:4173`。不要更换端口后误以为记录丢失：浏览器存储与网址来源相关。请使用 HTTPS 或上面的 localhost 服务器，并选择支持 Web Locks 的浏览器。直接打开 `docs/index.html` 可能只能只读，不应用于可靠保存。

发布操作与实际部署状态请以仓库和 Pages 设置页为准。部署步骤如下：

1. 使用已经创建的独立仓库，先检查现有内容。
2. 将本项目完整提交到该仓库的 `main` 分支。
3. 在仓库 Settings → Pages 选择 **Deploy from a branch**，分支选择 `main`，目录选择 `/docs`，保存。

```sh
gh repo create Suqi854/guokao-fujian-study --public --source=. --remote=origin --push
```

此命令仅适用于目标确实不存在的情况。若仓库已存在，应先检查归属、权限和内容，再添加远端并推送，避免重复创建或覆盖。

GitHub Pages `/docs` 配置保证只部署 `docs/` 中的静态网站文件。代码使用相对资源路径与 hash 路由，适配项目子路径，不需要服务器路由重写、构建步骤或第三方 CDN。

## 私人记录与备份

新版记录保存在当前浏览器的 `localStorage`，键为 `zhixu-study-v2`。首次读到旧 `zhixu-study-v1` 时只在内存转换，首次成功保存后才生成新版；旧键原文不写不删。旧标签页仍可能独自改旧键，不会与新版合并，升级前后应关闭旧标签并保存私人备份。没有远程数据库、上传接口或遥测。

所有新版写入在 Web Locks 独占锁内核对原始快照，发现其他标签的更改便停止保存，不做猜测合并。缺少锁、额度不足、存储权限或内容校验失败时明确提示，只保留页面副本供导出，不声称已保存。重置只重置新版，旧副本保留但不自动复活。运行中的选择题冻结题号、答案、模块及内容指纹（含共用表格）；内容变化后不可继续旧训练，但可结束保留历史。保留稳定题目与任务ID以便未来版本读取历史。数据不会自动跨设备同步，清理网站数据会清除记录。换域名、端口或协议前请导出；换 GitHub Pages 仓库路径时也建议导出后恢复。相同 origin 下的其他网页脚本可能访问同源存储，因此不要在同一 GitHub Pages 域名部署不可信代码。

备份中包含私人笔记、草稿和答题历史，应保存到私人文件夹；不要拖入公开仓库。`.gitignore` 已忽略备份常用命名、`.env*` 和私人资料目录，但不能代替人工检查暂存文件。

- `docs/quant-model-paths.js`：利润、浓度、概率、容斥与抽屉原理三层讲解及30道原创题。
- `docs/precision-sampling-paths.js`：估算、不放回、三集合与下文推断四课三层讲练，共24道原创题。
