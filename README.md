# 知序 · 国考与福建省考学习工作台

独立静态网站，面向手机，也适配平板和桌面。无需 ChatGPT、登录服务或 API 密钥；部署后运行不依赖 GPT 订阅。当前是**知识基础版 v0.10**，不是完整考试教材或真题库。

访问：[GitHub Pages 网站](https://suqi854.github.io/guokao-fujian-study/)；查看站内“资料来源与覆盖”了解依据、年份及尚待补充的范围。

## 本版内容和功能

- 72 篇讲义：资料分析10、判断推理12、言语理解11、数量关系14、政治理论2、常识判断7、福建专题1、申论方法15。
- 156 道原创选择题：资料分析34、判断推理30、言语理解31、数量关系38、政治理论4、常识判断17、福建专题2。均非历年真题。
- 22 个原创虚构材料写作练习（19份不同材料）：概括、对策、应用文、文章、综合分析，含一组地方情境训练，包括材料拆解、答案修改、对策落实、应用文对象、论证段、句意解释及同材料不同任务训练。早期文章任务提供提纲，新增w19提供600—900字完整文章任务与704字参考表达；均非官方评分，无自动打分。
- 4 个原创交互图形演示：同步旋转、并集/交集/异或、正方体相对面、柱高投影；图形题使用原创示意图。
- 18 项公开事实与范围参考资料：页面逐篇标注来源、年代、事实依据范围；解题方法、数学例子与练习独立编写。大纲只用于核对2026年度题型范围，不据此保证新年度覆盖。
- 题库检索：关键词、模块、题型、知识点、学习方向、真题来源、年份、难度标定、本机作答状态。可练筛选结果；目前真题来源为空、原创题无考试年份、难度未标定。
- 7个同知识点方法对照，每个有2份出处；共15份方法资料，区分7份历史教学资料、3份署名文章和5份机构资料。定义判断、估算与细节判断已有两份具名教学资料，其他专题仍有缺口，不转载商业题、模板或全文。
- 72道选择题按识别概念、迁移运用、检查边界各24题编排；可按训练层次筛选。层次是编写目标，不是经样本标定的难度；此前84题保持未分层。
- 福建2026考情快照：官方公告、分类合格线与核验缺口；没有把旧年度规则当2027安排。
- 针对性练习：先按模块与训练目标筛选，本机最近答错优先、未练题补足，跨知识点轮流取题，最多12题；显示规则和原因，不推断能力或遗忘周期。
- [覆盖矩阵](COVERAGE.md)：按模块和建设状态检索72个已有专题及24处明确缺口，显示实际讲义、题目和写作任务数量；不宣称官方完整范围或完成率。
- 方法对照：工程、比重已有两种解法；本轮主旨对照结构概括与选项反查，定义对照完整条件表与必要条件优先。本站操作组织与例题独立编写，历史来源的身份与边界另列，不冒称新增名师覆盖。
- 多表共用材料与逐项解析：v0.8起新增的27题给出每个选项的判断理由，选择题提交后展开；旧题尚未全部补齐逐项说明。
- 搜索、分类、收藏、已读标记、个人笔记、配套练习、综合练习、逐题解析、错题重练、学习统计。
- 申论按五类任务、关键词与本机草稿状态交集筛选，明确命中数量；同材料的不同设问互相链接，答案分别保存。
- 申论草稿即时保存、字数自查、参考要点、自查勾选、草稿 TXT 导出。
- 完整 JSON 备份和恢复；导入先校验，再确认替换；损坏数据不会被静默覆盖。

数量不代表学精：多数旧讲义仍是短篇入门，选择题变式和申论长材料都不足。本轮把主旨概括、定义判断两课深化到约1250字正文，尚未完成全站深度改写。

尚未覆盖完整政治理论和年度时政、断代史与文学全体系、复杂空间重构、全部言语数量题型、福建文化与政策专题。既有知识手册及原型未成功下载，未并入本版。备考方向仅记录目标，本版不是两套独立题库。所有旧版记录ID保持不变，可以继续使用和恢复v1备份。

## 本地预览

需要 Python 3：

```sh
python3 -m http.server 4173 --directory docs
```

打开 `http://localhost:4173`。不要更换端口后误以为记录丢失：浏览器存储与网址来源相关。也可直接打开 `docs/index.html`，但不同浏览器对本地文件存储的支持不一致；推荐使用上面的本地服务器。

## 发布到新的 GitHub 仓库

目标为 [Suqi854/guokao-fujian-study](https://github.com/Suqi854/guokao-fujian-study)，已创建为独立公开仓库；**不要将这些文件提交到已有股票项目**。

发布操作与实际部署状态请以仓库和 Pages 设置页为准。部署步骤如下：

1. 使用已经创建的独立仓库，先检查现有内容。
2. 将本项目完整提交到该仓库的 `main` 分支。
3. 在仓库 Settings → Pages 选择 **Deploy from a branch**，分支选择 `main`，目录选择 `/docs`，保存。
4. 等待 Pages 构建完成，使用设置页返回的 Visit site 地址验证。不要把预期网址当作已上线网址。

只有在复制到其他尚不存在的新仓库时，才使用创建命令。当前目标仓库已存在，不要重复执行：

```sh
gh repo create Suqi854/guokao-fujian-study --public --source=. --remote=origin --push
```

此命令仅适用于目标确实不存在的情况。若仓库已存在，应先检查归属、权限和内容，再添加远端并推送，避免重复创建或覆盖。

GitHub Pages `/docs` 配置保证只部署 `docs/` 中的静态网站文件。代码使用相对资源路径与 hash 路由，适配项目子路径，不需要服务器路由重写、构建步骤或第三方 CDN。

官方部署参考：[Creating a GitHub Pages site](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)。

## 私人记录与备份

记录保存在当前浏览器的 `localStorage`，键为 `zhixu-study-v1`。没有远程数据库、上传接口或遥测。数据不会自动跨设备同步，清理网站数据会清除记录。换域名、端口或协议前请导出；换 GitHub Pages 仓库路径时也建议导出后恢复。相同 origin 下的其他网页脚本可能访问同源存储，因此不要在同一 GitHub Pages 域名部署不可信代码。

备份中包含私人笔记、草稿和答题历史，应保存到私人文件夹；不要拖入公开仓库。`.gitignore` 已忽略备份常用命名、`.env*` 和私人资料目录，但不能代替人工检查暂存文件。

## 内容维护

- `docs/content.js`：讲义、原创题目、申论材料及参考。保留稳定 ID，避免影响旧记录。
- `docs/expansion.js`：来源登记、扩充讲义和原创题、覆盖范围。
- `docs/deepening.js`：人文、立体、言语、数量与申论深化；`catalog.js`：题目分类与来源档案；`methods.js`：历史方法出处索引。
- `docs/crossstudy.js`：同知识点专题与分层原创题；`comparisons.js`：来源盘点、方法对照及福建2026快照。
- `docs/app.js`：交互与本机记录，内置备份校验。
- `docs/style.css`：响应式布局和动效，支持减少动态效果偏好。
- `docs/index.html`：入口；`docs/icon.svg`：图标。
