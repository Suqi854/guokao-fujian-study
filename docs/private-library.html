本机私人题库

这是独立实验性功能，不属于公开原创题库。仅导入自己合法取得、可用于个人学习的内容。本站不会核验来源或答案，也不会据此取得公开转载许可。

先了解保存边界

  • 文件内容只在本页读取，题库保存在当前设备、浏览器和网站来源（协议、域名、端口）的 localStorage，不自动上传或跨设备同步。
  • 清理网站数据、隐私模式关闭或浏览器清理可能导致丢失。换网址/设备前，分别导出私人题库、主站学习记录，以及使用过的长题组备份。
  • 三种备份分开：主站 v1/v2 不含私人题库或长题组；私人备份不含主站或长题组记录，也不含本页临时选择和草稿。
  • 本机存储并非加密保险箱，同源网页脚本及有权限的浏览器扩展可能读取。请勿在不可信同源页面使用，备份不要放进公开仓库。
  • 页面需要正常加载，没有实现离线缓存。只支持 UTF-8 JSON 纯文本，不支持 PDF/OCR、图片、HTML、外链材料下载或抓取题库。
  • 单题包最多 1 MiB、1000 题；备份最多 2 MiB；合计最多 30 个题包、3000 题及约 2 MiB。浏览器剩余额度仍可能不足。
